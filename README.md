# Gallery Compare

Gallery Compare is a web application that allows users to compare paintings side by side to easily observe visual differences.

## Tech Stack

- React
- Vite
- JavaScript
- HTML & CSS
- Node.js & npm

## Prerequisites

Make sure you have the following installed:

- Node.js (LTS recommended)
- npm (comes with Node.js)

Verify installation:

```bash
node -v
npm -v
```

## Installation

Navigate to the project directory and install dependencies:

```bash
cd gallery-compare
npm install
npm run dev
```

Lastly, check your terminal and open the localhost link shown (usually `http://localhost:5173`).
